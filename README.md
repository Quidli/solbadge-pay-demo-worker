# Connect Pay demo worker

The Cloudflare Worker behind the Connect Pay demo on the Solana Breakpoint badge.
It was made in one click with the **Deploy to Cloudflare** button from
[Quidli/connectpay-solanabadge](https://github.com/Quidli/connectpay-solanabadge),
which has the badge app, the docs and the tests. Start there to run your own.
