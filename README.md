# SolBadge Pay demo worker

The Cloudflare Worker behind the SolBadge Pay demo on the Solana Breakpoint badge.
It was made in one click with the **Deploy to Cloudflare** button from
[Quidli/solbadge-pay](https://github.com/Quidli/solbadge-pay),
which has the badge app, the docs and the tests. Start there to run your own.
